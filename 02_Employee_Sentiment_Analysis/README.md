# Employee Sentiment Analysis

###  Project Overview
This project analyzes employee reviews to understand overall sentiment (Positive, Negative, Neutral) and extract key themes that impact employee experience.

###  Objective
- Classify employee feedback into Positive, Negative, and Neutral
- Identify major themes from reviews
- Generate actionable insights for HR teams

###  Tools Used
- Python
- TextBlob (Sentiment Analysis)
- WordCloud
- Matplotlib & Seaborn
- Pandas

###  Key Insights
- Positive feedback mainly highlights supportive management, good culture, learning opportunities, and work-life balance.
- Negative feedback frequently mentions toxic environment, excessive overtime, poor communication, lack of recognition, and compensation issues.
- Management behavior and workload have strong influence on employee sentiment.

###  Business Recommendations
- Conduct manager effectiveness training
- Review workload and reduce excessive overtime
- Implement regular employee recognition programs
- Benchmark salaries with market standards
- Continue strengthening positive cultural practices
